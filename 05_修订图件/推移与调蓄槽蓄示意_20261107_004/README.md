## 正文修改

**第3节，式（9）之前。**

如图X所示，上游入流开始增加而下游出流尚未起涨时，河段槽蓄量已随来水增加。RWEC将河道洪水演进概化为推移和调蓄两个环节。上游入流整体后移 $\tau$ 后作为调蓄单元的入流。以上游入流与推移后入流的累计水量差表示推移蓄量，以推移后入流与下游出流的累计水量差表示调蓄蓄量。在图示时刻，两者分别为 $S_1-S_2$ 和 $S_2+S_3$，相加得到河段槽蓄量的变化 $S_1+S_3$。其中，$\tau$ 决定入流过程的推移量，水能互补方程决定到达水量的滞蓄与释放，模型中的 $S_t$ 表示调蓄单元的有效滞蓄状态。

**图X　河段推移蓄量与调蓄蓄量示意。** $t_0$ 为图示推移后入流的起涨时刻，$t$ 为计算累计水量的截止时刻。阴影均按图示洪水增量计。若引用原图作为改绘来源，排版前在图注补上核实后的原始出处。

**第4.2节，峰时误差来源。**

以同一场洪水的上游洪峰时刻为起点，推移单元使入流洪峰后移 $\tau$。若仅推移所得的洪峰早于参照洪峰，其提前量来自有效推移时间与参照总峰滞时之差。推移后的入流进入调蓄单元后，各时段水量的保留与释放改变了出流过程，演算洪峰相对于纯推移峰时的净调整量为 $T_{\mathrm{RWEC}}-\tau$。这里，$T_{\mathrm{RWEC}}$ 为RWEC演算出流与上游入流的洪峰时间差，$t_{\mathrm{ref}}$ 为参照出流与上游入流的洪峰时间差。当仅推移所得的洪峰偏早时，调蓄引起的后移可以补偿这一提前量；若后移超过参照峰时，最终偏差也可能由提前转为滞后。

正文不加入起涨推移时间的相关系数、平均差或两参数对照精度。若保留原表7，需要让表中数值与正文所选口径一致。原表按离散时段平均入流峰时统计；改用纯推移量 $\tau$ 后，须用下面重新汇总的数值，不能混用。

## 审稿回复建议

感谢审稿专家的建议。修订稿补充了推移与调蓄示意，并以显式推移量 $\tau$ 为基准分解峰现时间误差。仅推移所得峰时相对于参照峰时的差为 $\tau-t_{\mathrm{ref}}$，调蓄后相对于纯推移峰时的净调整为 $T_{\mathrm{RWEC}}-\tau$，两者的有符号和为最终峰时误差。对1080个测试场次与断面组合，纯推移后的洪峰平均早于参照洪峰3.01 h，后续演算使峰时平均后移4.48 h，最终平均晚1.47 h。相应的峰时平均绝对误差由3.04 h降至1.67 h。这说明调蓄总体上补偿了纯推移造成的峰时提前，但并非每场洪水都恰好补足。

为考察 $\tau$ 的传播含义，另由HEC-RAS上下游过程识别起涨推移时间。上下游分别取洪水施加前0～24 h稳定段的流量中位数为基础流量，以上游洪峰增量的1%为共同增量阈值，取首次连续两条记录超过各自基础流量加阈值时的第一条时刻为起涨时刻。在C1～C3和12个传播距离组成的36个组合中，率定期和测试期的断面平均起涨推移时间与率定 $\tau$ 的Pearson相关系数均为0.996，平均分别比 $\tau$ 长1.62 h和1.49 h。

进一步以各场已知起涨推移时间代入 $\tau$，每个断面用70场洪水共同率定一组 $k,n$，再用该组参数演算30场测试洪水。两参数对照的率定期、测试期平均NSE分别为0.9670和0.9727；原三参数RWEC分别为0.9879和0.9885。结果支持以 $\tau$ 表征入流的有效推移，并由互补关系描述后续调蓄；逐场直接替代后的精度有所下降，说明两种时间不能逐场等同。该对照以已知起涨推移时间为条件，测试时的起涨推移时间由HEC-RAS参照出流提取。

**修改位置：** 第3节式（9）前的图及槽蓄解释，第4.2节峰时误差来源段。11月5日回信将峰时误差来源列在审稿人2意见1，最终稿按意见原文对应。
